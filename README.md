# Lumina Lens — Professional Photographer Portfolio Template

Thank you for purchasing **Lumina Lens**! This is a modern, responsive, luxury portfolio website template crafted specifically for photographers, videographers, visual artists, and creative professionals.

---

## 🌟 Key Features

- **100% Pure HTML5 & CSS3:** Strictly zero JavaScript dependencies, lightweight and lightning-fast loading speed.
- **Fully Responsive:** Flawless layout on desktop, laptop, tablet, and mobile displays.
- **Luxury Light Aesthetic:** Clean white & ivory background, crisp typography, and rich gold accents.
- **Pure CSS Mobile Navigation:** Smooth slide-out mobile drawer using pure CSS checkbox hack.
- **Curated Sections:**
  - Hero Section with high-resolution photographer portrait & live status badge
  - About Section with storytelling bio and achievement highlight cards
  - Experience Timeline with career milestones
  - Services Showcase with luxury gradient icon cards
  - Portfolio Showcase with category chips & hover zoom
  - Direct Contact Section with direct WhatsApp, Gmail, and Instagram action buttons (No database or backend form setup needed!)
- **SEO & Social Friendly:** Clean semantic markup with OpenGraph meta tags.

## 🚀 How to Customize

### 1. Changing Your Name & Bio
Open `index.html` in any text editor (such as VS Code, Sublime Text, or Notepad):
- Search for `Kabir Varma` and replace it with your own name.
- Search for the bio paragraphs inside the `<section id="about">` and edit the text.

### 2. Changing the Hero Photo
Replace `assets/images/hero-photographer.jpg` with your own portrait photo (recommended aspect ratio: 3:4 or 4:5, e.g. 800x1066px). Keep the filename the same or update the `src` path in `index.html`.

### 3. Adding Your Own Photos to the Portfolio
In `index.html`, locate the `<section id="projects">` section:
- Place your photo files inside `assets/images/projects/`.
- Update the `<img src="assets/images/projects/your-photo.jpg">` tags, titles, and descriptions.

### 4. Updating Contact Details
In `index.html`, locate the `<section id="contact">` section:
- **WhatsApp:** Replace `https://wa.me/919876543210` with your phone number (including country code, no `+` sign in the link).
- **Email:** Replace `contact@kabirvarma.com` with your active Gmail or custom email address.
- **Instagram:** Replace the Instagram URL with your profile link.
