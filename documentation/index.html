1. Introduction

Thank you for purchasing Lumina Lens! This template is an ultra-modern, luxury portfolio crafted specifically for photographers, videographers, visual artists, and creative professionals.

It is built with 100% pure HTML5 and CSS3. It does not require any JavaScript libraries, Node.js, npm, webpack, or databases. It loads instantly and works flawlessly across desktops, tablets, and smartphones.

Key Benefit: You can edit any text or link by opening index.html in any simple text editor (such as VS Code, Sublime Text, or Notepad) and double-clicking the file to view your changes in any web browser.

3. Installation & Local Preview

  1. Unzip: Extract the downloaded lumina-lens-main-files.zip file onto your computer.
  2. Open in Browser: Double-click the index.html file. It will immediately open and run in your default web browser (Chrome, Edge, Firefox, Safari).
  3. No Server Required: You do NOT need XAMPP, Apache, Node.js, or local servers. Pure HTML/CSS runs natively anywhere.
  4. Edit Code: Open the extracted folder in a code editor like Visual Studio Code to start customizing.

5. Customizing the Hero Photo

The hero section features a luxury card displaying a photographer portrait holding a camera with an availability badge.

In index.html (around lines 90–98):

<!-- Hero Visual (Professional Photographer Portrait) -->
<div class="hero-visual">
  <div class="hero-photo-wrapper">
    <img src="assets/images/hero-photographer.jpg" alt="Your Name" class="hero-photographer-img" width="500" height="667">
    <div class="hero-photo-badge">
      <span class="hero-photo-badge-dot"></span>
      <span>Available for Global Shoots</span>
    </div>
  </div>
</div>

How to Replace with Your Photo:

  1. Take your own portrait photo (recommended aspect ratio: 3:4, e.g., 900 × 1200 px).
  2. Save it as a JPG or PNG file.
  3. Either overwrite assets/images/hero-photographer.jpg with your file, or place your image in assets/images/ and update the src attribute in index.html.

7. Contact Section Configuration

Lumina Lens uses a modern direct contact system with one-click actions instead of a generic backend form. Buyers can contact you immediately via WhatsApp, Email, and Instagram without server setups.

In index.html, locate the contact cards around lines 401–436. Here are the exact code snippets and how to customize them:

Card 1: Direct WhatsApp & Phone (Line 403)

<!-- Card 1: Direct WhatsApp & Phone -->
<div class="contact-card">
  <div class="contact-icon-bubble">💬</div>
  <div class="contact-type">Direct WhatsApp & Phone</div>
  <div class="contact-value">+91 98765 43210</div>
  <p class="contact-subtext">Available Mon — Sat, 10:00 AM – 7:00 PM IST</p>
  <a href="https://wa.me/919876543210" target="_blank" rel="noopener" class="contact-btn">
    <span>Chat on WhatsApp →</span>
  </a>
</div>
  • To update your WhatsApp link: In href="https://wa.me/919876543210", replace 919876543210 with your country code and phone number (without spaces, dashes, or the + sign). Example: for US number +1 234 567 8900, write https://wa.me/12345678900.
  • Display Text: Update the text inside <div class="contact-value"> to your formatted phone number.
  • Optional Direct Call (tel:): If you want the button to trigger a direct phone call instead of WhatsApp, simply change the href to href="tel:+919876543210" and the button text to Call Now →.

8. Colors & Styling Guide

All colors, fonts, and spacing are defined using centralized CSS Custom Properties (Variables) at the very top of assets/css/style.css (lines 9–50):

:root {
  /* Theme Colors */
  --bg-dark: #f8f9fa;               /* Main background color */
  --bg-surface: #ffffff;            /* Card background color */
  --bg-surface-elevated: #f1f3f5;   /* Secondary card background */

  /* Text Colors */
  --text-main: #111827;             /* Heading & primary text */
  --text-muted: #475569;            /* Subtitles & body text */

  /* Luxury Accent Colors */
  --accent-gold: #b48a28;           /* Primary gold accent */
  --gold-gradient: linear-gradient(135deg, #d4af37 0%, #b48a28 50%, #856113 100%);

  /* Typography */
  --font-serif: 'Playfair Display', Georgia, serif;
  --font-sans: 'Plus Jakarta Sans', system-ui, sans-serif;
}

Changing these values will instantly update the entire website's appearance consistently across all sections.

10. Troubleshooting & FAQ

Q: Do I need to install Node.js, npm, or any build tools?

A: No! Lumina Lens is built with 100% pure vanilla HTML5 and CSS3. There are no build tools or package managers required. Simply double-click index.html.

Q: Why does the contact section have WhatsApp and Email instead of a form?

A: A static HTML form without a backend server or PHP script does not actually deliver emails. Lumina Lens uses high-converting direct WhatsApp and Gmail links so your clients can contact you instantly without delivery failures.

Q: My new images aren't showing up after replacing them. Why?

A: Browsers often cache images. Press Ctrl + F5 (Windows) or Cmd + Shift + R (Mac) to hard-refresh the page and clear your browser cache.
